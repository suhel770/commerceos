# CommerceOS Inventory

Status: Frozen

The Inventory module manages stock across warehouses and marketplaces from a single source of truth.

## Workspace UI (ops-first)

`/inventory` is an **Inventory Operations Command Center** (not a traditional ERP
grid-first page): Today’s Inventory → Health score with reasons → optional
Advisor / Forecast / Warehouse / Marketplace widgets (capability-gated) → stock
table + inspector. AI is optional and never auto-mutates stock. Core engine
rules remain in this chapter’s frozen docs.
